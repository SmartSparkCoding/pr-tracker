This is an **example** pull request entry, added to demonstrate how the tracker works.

Each pull request is a single markdown file in `src/content/prs/`. Copy this file, update
the frontmatter, write a short description of the change, and the site rebuilds automatically.

- The **status badge** is pulled live from GitHub whenever the PR link is valid.
- Featured entries (`featured: true`) are pinned to the top of the homepage.
- Everything else is sorted from newest to oldest by `date` (and `time`).

Delete this file and add your own entries to get started.
